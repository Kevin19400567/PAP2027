## Descrição

O KELSONVERSE é uma plataforma web dedicada ao artista angolano Kelson Most Wanted. O objetivo é criar um espaço onde os fãs possam conhecer melhor o artista, consultar a sua carreira, músicas, álbuns e conteúdos multimédia. A plataforma permitirá pesquisar e explorar os conteúdos de forma simples e organizada. Terá também uma área administrativa, onde será possível adicionar, editar e eliminar informações. O projeto pretende reunir num único local informações importantes sobre o artista.

## Objetivos

- Criar uma plataforma web moderna, organizada e fácil de utilizar.
- Disponibilizar informações sobre a carreira, músicas e álbuns de Kelson Most Wanted.
- Desenvolver uma área administrativa para gerir os conteúdos do site.

## Funcionalidades

### Núcleo mínimo (obrigatório)

- [ ] Página inicial com apresentação do artista.
